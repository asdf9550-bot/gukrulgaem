# 다른 PC(5600G)에서 사이트 자동 수집·올리기

사이트 수집기는 파이썬 기본 기능만 써서 **GPU 없이** 돌아갑니다. 5600G·32GB면 충분합니다.
하는 일: 매일 **00:05·12:05**(어복 재고관리 00:00·12:00이 끝난 뒤)에 스팀 할인 게임을 수집 → `data\` 갱신 → GitHub에 올림 → Vercel이 사이트를 다시 만듦.
어복 재고관리(`어복_재고관리.exe`)가 아직 돌고 있으면 끝날 때까지 기다렸다가 시작합니다(최대 3시간). 같은 인터넷을 쓰는 두 작업이 겹치지 않게 하려는 것입니다.

## 1. 폴더 옮기기 (둘 중 하나)

**A안 (추천) USB로 복사**
1. 이 PC의 `C:\Users\PC\Documents\Codex\스팀 구매 가이드 사이트` 폴더를 통째로 USB에 복사합니다.
   `web\node_modules`, `web\.next` 폴더는 빼도 됩니다(수집에는 필요 없음, 1GB 넘음).
2. 새 PC의 `C:\gukrulgaem` 에 붙여 넣습니다. (한글·공백 없는 경로가 안전합니다)
   `.env` 파일이 같이 복사됩니다. 키를 채팅이나 메일로 옮기지 마세요.

**B안 GitHub에서 받기**
1. 새 PC에서 PowerShell을 열고: `git clone https://github.com/asdf9550-bot/gukrulgaem.git C:\gukrulgaem`
   (Git이 없으면 아래 2단계의 설치 스크립트를 먼저 실행하세요. 비공개 저장소라 브라우저 로그인 창이 뜹니다.)
2. 이 PC의 `.env` 파일을 USB로 `C:\gukrulgaem\.env` 에 복사합니다.

## 2. 설치 (새 PC에서, 한 번)

`C:\gukrulgaem\설치_다른PC\1_설치.ps1` 을 **마우스 오른쪽 → PowerShell로 실행**합니다.
- Python 3.12와 Git이 없으면 winget으로 설치합니다.
- `.env` 가 없으면 `.env.example` 을 복사해 메모장으로 엽니다 → `ITAD_API_KEY=` 뒤에 키를 붙여 넣고 저장.
  (`ANTHROPIC_API_KEY` 는 "좋아한·싫어한 이유" 요약용, 없으면 건너뜁니다)
- 예약 작업 `Gukrulgem-Site-AfterInventory` 를 등록합니다 (매일 00:05·12:05, 절전 중이면 깨워서 실행).

## 3. 시험 (새 PC에서, 한 번)

`3_시험.ps1` 을 PowerShell로 실행합니다.
- GitHub 로그인 확인(처음이면 브라우저 로그인 창이 뜸 → 계정 asdf9550-bot 로 로그인)
- 게임 3개만 수집해 봄(저장 안 함) → 가격·판정이 표로 나오면 성공
- `git push --dry-run` 으로 올리기 권한 확인

## 4. 이 PC(영상 PC)의 예약

영상 PC의 `Gukrulgem-Daily-0440`(04:40 수집)은 2026-10-13 밤에 이미 꺼져 있습니다. 그대로 꺼 두세요.
두 PC가 같은 시간에 올리면 충돌이 나니 사이트 수집은 5600G 한 곳에서만 합니다. (영상 프로그램이 올리는 영상 목록은 그대로 이 PC에서 올라가며, 양쪽 스크립트가 올리기 전에 `git pull --rebase` 를 해서 겹쳐도 합쳐집니다.)

## 새 PC 조건
- 매일 00:05·12:05에 켜져 있거나 절전(최대 절전) 상태여야 합니다. 완전히 꺼져 있으면 그날은 건너뜁니다.
  Windows 설정 → 전원 → "절전 모드 해제 타이머 허용" 이 켜져 있어야 깨어납니다 (설치 스크립트가 켭니다).
- 로그인된 사용자로 실행됩니다. 기록은 `C:\gukrulgaem\output\auto_YYYYMMDD.txt`.
